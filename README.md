# Parcial 2 - Fullstack II

Proyecto de la segunda evaluación parcial del ramo Fullstack II (Duoc UC).

Repo: https://github.com/SAAB85/FULLSTACK_PARCIAL2

## Estado

Esqueleto en blanco (React + Vite + ESLint). Pendiente portar el trabajo de la
Evaluación Parcial 1 (Ferretería Los Maestros) de a poco.

## Comandos

```bash
npm install      # instalar dependencias
npm run dev      # servidor de desarrollo
npm run build    # build de producción
npm run lint     # eslint
npm run preview  # previsualizar el build
```
